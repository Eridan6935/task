# BUGFIX — найденные и исправленные ошибки

## Проверенные ошибки

1. **Пустое название задачи.** Раньше можно было добавить пустую строку. Теперь `create_task()` проверяет название и не добавляет пустые задачи.
2. **Неверный номер задачи.** При редактировании и удалении проверяются границы списка; номер начинается с 1.
3. **Ввод букв вместо номера.** Преобразование номера обрабатывается через `try/except ValueError`, приложение не завершается аварийно.
4. **Неподдерживаемый пункт меню.** Приложение сообщает об ошибке и продолжает работу.
5. **Отмена действия.** Редактирование и удаление требуют подтверждения.
6. **Отсутствующий файл данных.** Если `tasks.json` ещё нет, приложение запускается с пустым списком.
7. **Повреждённый JSON или ошибка чтения.** Ошибки перехватываются, выводится понятное сообщение.
8. **Ошибка записи.** `save_tasks()` возвращает `False` и сообщает об ошибке, вместо аварийного завершения.
9. **Проблемы с русским текстом.** JSON читается и записывается в кодировке UTF-8 с `ensure_ascii=False`.

## Как тестировать вручную

- Добавить задачу с обычным названием.
- Попробовать добавить пустую задачу.
- Отредактировать существующую задачу и ввести несуществующий номер.
- Удалить задачу и отменить удаление.
- Ввести буквы вместо номера.
- Запустить приложение без `tasks.json`.
- Перезапустить приложение и убедиться, что сохранённые задачи загружаются.
