# Task Manager — версии 0.0.9–0.1.0

Консольное приложение для создания и управления списком задач.

## Запуск
1. Откройте папку проекта в PyCharm.
2. Запустите `main.py`.
3. Выберите действие в меню.

Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

## Модули
- `main.py` — цикл приложения и история улучшений.
- `view.py` — консольное отображение.
- `utils.py` — подтверждение действий.
- `core.py` — операции с задачами.
- `storage.py` — JSON-хранилище.
- `tasks.json` — данные приложения.
- `BUGFIX.md` — исправленные ошибки и тесты.
- `BACKLOG.md` — история версий 0.0.1–0.1.0.

## Проверка
Проверьте добавление, отображение, редактирование, удаление, отмену действий и сохранение после перезапуска.
