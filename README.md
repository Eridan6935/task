# Task Manager

Консольный менеджер задач на Python. Проект разделён на модули:

- `main.py` — главный цикл приложения и обработка команд.
- `view.py` — отображение меню, списка задач и сообщений.
- `utils.py` — подтверждение действий пользователя.
- `core.py` — создание, редактирование и удаление задач.
- `storage.py` — загрузка и сохранение задач в `tasks.json`.

## Запуск

Требуется Python 3.10 или новее.

1. Откройте папку проекта в PyCharm.
2. Запустите `main.py`.
3. Выберите пункт меню от 1 до 5.

Файл `tasks.json` создаётся автоматически при первом сохранении.
